# EarLoop · 精听循环

> 专治「看得懂，听不懂」

## 这解决的是什么痛点？

这是中国英语学习者最普遍、也最 frustrate 的痛点：

- 单词都认识，阅读能看懂
- 一听就懵，脑子跟不上，听完不知道说了什么
- 尤其是雅思 Part 3 / Part 4、职场会议、影视台词

原因不是词汇量，而是**耳朵不认识连读、弱读、吞音后的词**。纸上认识 ≠ 耳朵认识。

EarLoop 不做泛听。它只做一件事：**逐句精听**。

## 怎么练？三步循环

1. **盲听默写** — 不看原文，听一句，写下你听到的
2. **对照纠错** — 系统逐词对比，听错/漏听的词标红，自动进「弱词本」
3. **跟读循环** — 原句循环播放 3 遍，跟读模仿连读和语调，再过下一句

一天练透 6-8 句，比囫囵听一整套题有效得多。

## 功能

- 🎧 **内置训练营**：18 句原创，分 3 组
  - IELTS Part 3 学术讨论（6 句）
  - IELTS Part 4 学术讲座（6 句）
  - 职场日常英语（6 句）
  - 每句带中文翻译 + 「听辨陷阱」讲解（连读/弱读/重音在哪）
- 📋 **粘贴练习**：粘贴任何英文（课文、新闻、演讲、台词），自动断句生成练习
- 🔊 **英音 / 美音切换** + 0.75× / 1.0× / 1.15× 语速（用设备系统语音）
- 📕 **弱词本**：自动收集你总是听不出的词，点词听发音，本地保存
- 🔥 **连续打卡 & 进度**：练透句子数、连续天数，存在本地
- 📱 **像 App 一样用**：支持添加到手机主屏幕（PWA），无需注册、无需下载、免费

> 内置句子均为按 Part 3/4 难度原创仿写，不使用剑桥真题原文或录音。

## 怎么打开

### 方式 1：GitHub Pages（推荐，分享给别人用）
仓库 Settings → Pages → Source 选 `main` 分支，保存后会得到一个公开链接，任何人打开就能练。

### 方式 2：直接打开文件
把 `index.html` 下载到手机/电脑，用浏览器打开即可（语音功能需要联网或系统语音支持）。

### 方式 3：本地预览
```bash
cd earloop-app
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 技术

纯原生 HTML + CSS + JavaScript，零依赖、零构建、零后端。数据只存在浏览器 `localStorage`，不上传任何内容。
