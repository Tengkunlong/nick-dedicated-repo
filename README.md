## ⭐ 旗舰项目：EarLoop · 精听循环

**解决一个很多人的痛点：看得懂，听不懂。**

单词都认识、文章能读懂，一听就懵 — 这是中国英语学习者最普遍的卡点。EarLoop 用「盲听默写 → 逐词纠错 → 跟读循环」逐句练，把耳朵练出来。

- 📂 代码：[`earloop-app/`](./earloop-app/)
- 🎧 内置 18 句原创训练：IELTS Part 3 / Part 4 / 职场英语，每句带翻译和听辨陷阱
- 📋 粘贴任何英文都能自动断句生成练习
- 📕 弱词本自动收集你听不出的词
- 📱 免费、无需注册、可添加到手机主屏幕

👉 用法见 [`earloop-app/README.md`](./earloop-app/README.md)，开启 GitHub Pages 后任何人打开链接就能练。
